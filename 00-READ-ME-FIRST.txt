Desktop vs Mobile
  • Best experience: Desktop/Laptop
  • Also works: Mobile browsers (responsive design)
  • Mobile network: Type computer's IP:5173

Backup Your Data
  • Go to Settings
  • Click "Export Data"
  • Save the JSON file
  • Keep as backup!

Restore from Backup
  • Go to Settings
  • Click "Import Data"
  • Select your JSON backup file
  • All data restored!

Multiple Profiles
  • Each profile is completely separate
  • Switch between profiles easily
  • Perfect for different study sessions


❓ COMMON QUESTIONS

Q: Where is my data stored?
A: In studymate.db file in this folder. Never uploaded anywhere.

Q: Can I access it on my phone?
A: Yes, use your computer's IP address on local network.
   Can expose globally with ngrok (see DEPLOYMENT.md).

Q: What if something breaks?
A: Delete studymate.db and restart. Or restore from backup.

Q: Do I need internet?
A: No! It works completely offline.

Q: Is it secure?
A: Yes! All data local, no tracking, no accounts, no login.

Q: Can I customize it?
A: Yes! See the code in backend/ and frontend/ folders.
