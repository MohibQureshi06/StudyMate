🔄 HOW IT WORKS

The application now runs as a single server:

  http://localhost:5000/          ← Frontend (React app)
  http://localhost:5000/api       ← Backend API endpoints
  http://localhost:5000/api/health ← API health check

The backend (Express server):
  • Serves all API endpoints under /api
  • Serves the built frontend files
  • Handles both frontend and backend requests
  • Single process, single port

⚙️ FOR DEVELOPERS

If you modify the frontend code:

1. Stop the server (Ctrl+C)
2. Run: npm run build
3. Run: npm run start
4. Refresh browser (Ctrl+R)

For development with live reload:
  npm run dev
  (This runs frontend on 5173 + backend on 5000 separately)


🛠️ TROUBLESHOOTING

"Port 5000 already in use":
  • Change PORT in backend/server.js
  • Or kill the process using port 5000

"Frontend not found":
  • Run: npm run build
  • Then: npm run start

"Database errors":
  • Delete studymate.db
  • Run application again (new database created)
