🆘 TROUBLESHOOTING

"npm not found"
  → Install Node.js from https://nodejs.org/
  → Restart computer after install

"Port 5000 already in use"
  → Close other applications using port 5000
  → Or change PORT in backend/server.js

"Frontend not loading"
  → Close browser (Ctrl+W)
  → Run: npm run build
  → Restart the batch file
  → Open http://localhost:5000 again

"Database errors"
  → Delete studymate.db file
  → Restart application (new database created)

"Still not working?"
  → Check SINGLE-PORT-SETUP.txt for more details
  → Or restart your computer
